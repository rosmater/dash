# Бизнес-дашборд — макеты v0.1 (19.10.2026)

Три варианта одного дашборда. Каждый — **один HTML-файл** (vanilla JS + Chart.js 4 с CDN), данные берутся из **одного `data.json`**.

| Файл | Дизайн |
|---|---|
| `variant-a.html` | **A — Light SaaS** (выбран Rost 24.10): светлая тема, KPI-карточки со спарклайнами, стек прибыли, донат; красные бейджи «требует внимания» на вкладках + блок причин; вкладка «Коучинг» (люди-подпроекты) |
| `variant-b.html` | **B — Executive (светлый)**: «газетная» сводка одной фразой, таблица направлений с итогом, крупные прогресс-бары целей, задачи по направлениям |
| `variant-c.html` | **C — Control room**: плотный терминальный вид, тепловая карта прибыли (направления × недели/месяцы, клик по ячейке открывает её), панель задач ClickUp с фильтрами (все / срочно / for check / вкладка) |
| `shots/` | Полностраничные PNG: `variant-X.png` (Общий, десктоп), `variant-X-peptides.png`, `variant-X-mobile.png` (iPhone 390 px) |
| `src/` | `build_data.py` (сборка data.json из базы знаний), `core.js` (общая логика), исходники вариантов, `build.sh`, `shoot.py` (скриншоты) |

Везде: вкладки **Общий / Личное / Недвижимость / Табакевич-кальяны / ОФ / Пептиды / Оборонка / Календарь / Коучинг** (порядок Rost 25.10), переключатель **Неделя ↔ Месяц**, выбор периода, всё в USD по курсу (Rost 25.10), цели vs факт, доход/расходы/прибыль/ROI, разбивки, задачи ClickUp, пробелы данных. Состояние (вкладка/период) запоминается в localStorage; можно передать `?mode=month&month=2026-08&tab=realestate`.

Открывать через http (GitHub Pages или `python3 -m http.server`), т.к. `data.json` грузится fetch'ем. Другой источник данных: `variant-a.html?data=https://…/data.json` (например, JSON-выгрузка Google Sheet через Apps Script).

## Схема data.json

```jsonc
{
  "meta": {
    "default_week": "2026-10-12",          // понедельник недели по умолчанию
    "default_month": "2026-10",
    "week_to_month_rule": "Неделя (пн–вс) относится к месяцу, в котором её понедельник",
    "fx": {                                 // все пересчёты идут через USD
      "USD_COP": {"rate": 3174.67, "date": "2026-10-19", "source": "TRM SFC"},
      "EUR_USD": {"rate": 1.1225, "date": "2026-10-19", "source": "ECB"},
      "USD_UAH": {"rate": 45.10, "date": "2026-10-19", "source": "BAS"}
    },
    "weeks":  [{"id": "2026-10-12", "start": "2026-10-12", "end": "2026-10-18", "month": "2026-10", "iso": "W42", "label": "12–18 окт"}],
    "months": [{"id": "2026-10", "label": "Октябрь 2026"}]
  },
  "directions": [{
    "id": "peptides", "name": "Пептиды", "subtitle": "…", "currency": "COP", "color": "#22d3a6", "icon": "💉",
    "overview_note": "необязательная оговорка для вкладки «Общий»",
    "periods": {
      "W:2026-10-12": {                      // неделя: ключ W:<понедельник>
        "status": "full|partial",
        "income":   [{"label": "…", "amount": 700000, "cur": "COP", "src": "откуда цифра", "example": false, "note": "…"}],
        "expenses": [{"label": "…", "amount": 200000, "cur": "COP", "src": "…"}],
        "metrics":  {"Продажи, шт.": 2},       // произвольные показатели
        "note": "комментарий"
      },
      "M:2026-10": {"rollup": true, "income": [], "expenses": [ /* статьи без недели */ ]},  // месяц = Σ недель + эти статьи
      "M:2026-08": {"status": "full", "income": [...], "expenses": [...]}                    // явный итог месяца (без rollup) — используется как есть
    },
    "goals": [{"label": "…", "unit": "%", "target": 100, "lower_is_better": false, "example": false,
               "period_type": "week|month", "by_period": {"W:2026-10-12": 75.8}, "src": "…"}],
    "breakdowns": [{"period": "W:2026-10-12" /* или null = всегда */, "title": "…", "columns": [...], "rows": [[...]]}],
    "tasks": [{"id": "86bb779rw", "name": "…", "status": "for check", "priority": "urgent|high|normal", "due": "2026-10-19", "list": "…", "url": "…"}],
    "gaps": ["что не найдено"]
  }],
  "overview": {"tasks": [...]}
}
```

Правила расчёта: **прибыль = Σ доходов − Σ учтённых расходов**; если расходов нет — показывается «расходы не учтены». **ROI = прибыль / расходы**. `amount: null` = факт есть, суммы нет. Месяц без явной записи = свёртка недель (неделя → месяц по понедельнику) + статьи `M:` с `rollup: true`. Любая статья/цель с `"example": true` получает в UI значок **«пример»**. Новое направление = ещё один объект в `directions` — вкладка появится сама.

### Подключение Google Sheet (следующий шаг)
Лист `periods` (строка = статья: direction, period_key, type income/expense, label, amount, cur, src, example) + лист `goals` + лист `tasks` → Apps Script `doGet()` отдаёт JSON этой схемы → `?data=<url>` или бот раз в неделю перезаписывает `data.json` в репо.

## Стадии направлений (Rost 24.10)
Цветная точка на карточках направлений во вкладке «Общий» (не на вкладках), легенда под карточками. Поле `stage` в `directions` (`src/build_data.py`):
- 🟢 `money` — есть деньги: Пептиды, ОФ, Недвижимость, Табакевич / кальяны
- 🟠 `launched` — запустились, денег пока нет: Оборонка (рассылка STE идёт, мониторы работают, дохода нет)
- 🟡 `starting` — стартуем: пока нет
- Личное — без точки (не бизнес, в «Общий» не входит)

Коучинг: две колонки — слева Алехандра, справа Мама → Андрей → Бабушка; в карточке сначала задачи, потом цель/метрики.
